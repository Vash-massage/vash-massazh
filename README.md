# Ваш массаж — итоговая версия сайта

## Что внутри
- `index.html` — главная страница.
- `services-body.html` — массаж тела.
- `services-figure.html` — моделирование фигуры.
- `services-face.html` — массаж лица.
- `services-combo.html` — комплексные программы.
- `style.css` — общие стили.
- `robots.txt` и `sitemap.xml` — базовая SEO-настройка.

## Важно
Папку `assets` на GitHub НЕ удаляйте. Все HTML-файлы используют уже загруженные туда изображения по тем же именам.

## Как загрузить на GitHub с телефона
1. Откройте репозиторий.
2. Нажмите `Add file` → `Upload files`.
3. Выберите все файлы из этого набора: `index.html`, `services-body.html`, `services-figure.html`, `services-face.html`, `services-combo.html`, `style.css`, `robots.txt`, `sitemap.xml`.
4. Не удаляйте существующую папку `assets`.
5. Внизу оставьте `Commit directly to the main branch`.
6. Нажмите зелёную кнопку `Commit changes`.
7. Подождите 1–3 минуты и обновите сайт.

Если GitHub покажет предупреждение о замене существующих файлов — подтверждайте замену именно этих файлов.
